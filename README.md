# Ezzeldin Amr | Portfolio

Personal portfolio for my IT, security and software-development work.

**[Open the live portfolio](https://ezzk9432.github.io/Ezzeldin-pro/)** · **[LinkedIn](https://www.linkedin.com/in/ezzeldin-amr-32ab31318/)**

## Interface

- Portfolio sections for experience, education, projects, skills and contact information.
- Terminal-style mode with commands for browsing the same portfolio content.
- Dark and light themes.
- Canvas background effects and GSAP animations.

## Technology

HTML, CSS and JavaScript in `index.html`. GSAP and Google Fonts load from external CDNs. No package installation or build step is required.

## Run locally

Clone the repository and open `index.html` in a modern browser. A simple static web server can also serve the repository root.

## Repository map

- `index.html`: page structure, styles, portfolio content and interactive behavior.
- `README.md`: project overview and maintenance notes.

## Maintenance notes

The website and this repository's documentation are separate from my GitHub profile README. When updating career facts or contact links, check both the normal interface and the terminal responses so they remain consistent. Verify phone and small-screen layouts after visual changes.

The site is a personal portfolio, not proof that each listed project is production-ready or independently security-audited. Project implementation details should be checked in the linked source repositories.
